# Checkpoint (session wrap-up)

Цель: оставить проект и доки в консистентном состоянии, чтобы следующая сессия
(или другой агент) продолжила без раскопок. Делать по порядку.

## 1. Доки актуальны

- `agents.docs/<surface>/TEST_PLAN.md` → обнови раздел **«▶ Продолжаем здесь»**
  (счётчик тестов, что сделано, что следующее).
- `KNOWLEDGE_BASE.md` → добавь новые находки по живому DOM (с датой «подтверждено DOM <дата>»).
- `CLAUDE.md` / `AGENT_HANDOFF.md` → поправь счётчики/статусы, если менялись.

## 2. Проверки

- `npx tsc --noEmit` — должно быть **0 ошибок** (хук qa-gate это же блокирует на пуше).
- Прогнать **затронутые** спеки (не весь набор): `npx playwright test <spec> --project=chromium`.
  Помни: прод живой — мутирующие тесты должны быть self-cleaning, прод оставить чистым.

## 3. Прибраться

- Удалить временные пробы (`tests/**/_recon.*.temp.spec.ts`, `tmp-*.mjs`) — не коммитить
  (см. память scratch-probe-convention).
- Убедиться, что не утекли секреты: `storageState*.json`, `.env`, креды — не в коммите.

## 4. Git (см. память git-autonomous)

- Коммит на **ветку, не main**; bilingual conventional-сообщение + `Co-Authored-By`.
- `git push`; дать ссылку на PR. Несвязанные изменения — отдельными коммитами/ветками.

## 5. Память

- Обнови relevant memory (`game-panel-next-focus` и пр.): новое состояние, следующий фокус.
- Только не-очевидное и не дублирующее репо (правило памяти).

## 6. Отчёт (см. память report-style-detailed)

Подробно: что сделано / почему / что переиспользовано / результаты тестов+tsc / что
пропущено и почему / явный **следующий шаг**. И спроси, продолжаем или хватит на сегодня.
