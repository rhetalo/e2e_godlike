## Правила (из CLAUDE.md / TEST_GUIDELINES.md, не нарушать)

- **«Эффект, а не факт»** — проверяем реальное изменение состояния (ответ сервера/БД/статус),
  а не только сообщение «Сохранено» на экране (ложная уверенность).
- **Изоляция** — кейс готовит свой precondition сам; не зависит от порядка/соседей.
- **Без хардкода** — данные через `fixtures/test-data.ts` / env, не в тексте кейса.
- **Live-prod** — только обратимые / self-cleaning флоу. Деструктив (rebuild, restore,
  списание промо) — отдельный risk-decision владельца, помечать явно.
- **Тег обязателен** — `@smoke` / `@critical` / `@regression` (+ `@flaky` если на карантине).
- ID `TC-<DOMAIN>-<FEATURE>-NNN` — сквозной, совпадает с заголовком теста в спеке (traceability).
