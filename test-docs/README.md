# test-docs — живая тест-документация (docs-as-code)

Этот каталог — **код-смежный слой** тест-документации: то, что должно версионироваться
вместе с автотестами, диффаться на ревью и читаться ИИ-агентом как контекст. Введён
17-Jun-2026 по итогам ресёрча QA/AI-практик (см. ниже «Источники идей»).

## Как это соотносится с остальным

| Где | Что лежит | Формат | Роль |
|-----|-----------|--------|------|
| `C:\Playwrite\e2e_browseruse\QA_test_docs\` | Полный ISTQB-комплект (00_INDEX … 10_execution_report) по `godlike.host` и `ultra.panel` | `.docx` | Нарративная база: стратегия, функциональное описание, план |
| **`test-docs/` (здесь)** | Шаблоны, глоссарий, трассируемость, живые тест-кейсы | Markdown в git | Источник истины для кейсов + контекст агента |
| Drivt (опц., `app.drivt.net`) | Импорт кейсов, ручные прогоны, отчёты | web-TMS | Витрина для людей / трекер ручных прогонов |
| `agents.docs/` | Знание для агента (гайдлайны, recon, code-review) | Markdown | Как писать тесты |
| `tests/**`, `pages/**` | Автоматизация | TypeScript | Исполнение |

**Принцип (гибрид):** источник истины по кейсам — Markdown здесь; Drivt и `.docx` —
производные витрины. Двустороннюю синхронизацию НЕ строим, пока Drivt не приживётся;
сначала проверить у Drivt наличие API/CSV-импорта.

## Структура

```
test-docs/
  README.md              # этот файл — карта + бэклог долга
  glossary.md            # словарь доменных терминов (повышает качество AI-генерации кейсов)
  templates/
    test-case.md         # шаблон Table-test (AC → заголовок, Test → шаги)
```

Тест-кейсы по продуктам добавляются по мере перевода из `.docx`:
`test-docs/<product>/<feature>.md` (1 фича = 1 файл, 5–15 экранов max — дробить крупное).

## Трассируемость кейс → автотест

Каждый Markdown-кейс в поле «Автоматизация» ссылается на спек-файл и наоборот.
ID кейсов сквозные: `TC-<DOMAIN>-<FEATURE>-NNN` (напр. `TC-GP-TASK-001`, как уже в
`tests/game/panel/tasks.spec.ts`). Это даёт traceability-matrix без отдельного инструмента:
grep по ID связывает требование → кейс → спек.
