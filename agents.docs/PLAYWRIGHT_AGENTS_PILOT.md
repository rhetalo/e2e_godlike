## Ловушки установки

1. **`init-agents` перезаписывает `.mcp.json` целиком** - удалил `godlike-wp`, `godlike-wp-sql`, `godlike-panel-sql`.
   Перед запуском - копия `.mcp.json`, после - слить. (`.mcp.json` у нас в `.gitignore`, в git не уходит.)
2. **Параллельные запуски Playwright стирают друг другу `test-results/`** → в основном прогоне падения `ENOENT ... .trace`.
   Любой параллельный запуск (агенты, burn-in) - со своей папкой: `--output=<другая папка>`.
3. Определения агентов - сгенерированные файлы: после обновления Playwright их надо пересоздавать (и снова сливать `.mcp.json`).
4. Seed в корне `tests/` не подхватывается ни одним проектом - нужен отдельный проект (у нас `agents`, `default: false`).
