# Каталог Minecraft-схематик /minecraft-schematics/

> **В двух словах.** Бесплатный каталог готовых построек для Minecraft. Игрок выбирает тематику или фильтрует
> по версии и формату, открывает карточку и скачивает файл под свою версию. Работы, версии, форматы и фильтры
> заводит контент-менеджер в WP-админке, разработчик не нужен. На 21-Oct-2026 только на stage.

## Где в интерфейсе

| Где | Что |
|---|---|
| `/minecraft-schematics/` | hero, 4 подборки (Houses / Castles / Spawns / Decorations) со счётчиком, тулбар: поиск, версия, формат, сортировка, свои группы (Style, Build size), 12 карточек на страницу |
| `?schematic=<slug>` | модалка: картинка / 3D Preview (Coming Soon), характеристики, выбор версии и формата, Download |
| `/?gl_schematic_file=<id>&version=<slug>&format=<ext>` | эндпоинт скачивания: 200 + `attachment`, `no-store`, `noindex` |
| WP-админка → «Схематики» | работы, Тематики, Версії, Формати, Фільтри, Налаштування каталогу |

## Как работает (под капотом)

- CPT `schematic`, таксономии `schematic_category` (одна на работу, radio), `schematic_version`, `schematic_format`,
  `schematic_filter` (группа → значения). Строки Carbon Fields «файл + версии», формат строки = расширение файла.
- Модалка знает доступность пар из `data-sch-availability` (`{"1-21-1":["litematic"],"1-20-1":["litematic","schem"]}`).
- Порядок терминов везде по полю «Порядок» (`gl_sch_order`), при равном - от новых версий к старым.
- JS `themes/godlike/js/schematics-catalog.js?ver=<filemtime>`; WP Rocket кеширует JS темы, после деплоя чистить.

## Правила и граничные случаи

1. Работа без строк файлов, без тематики или с дублем версии в одном формате при публикации уходит в черновик
   (красное уведомление с названием работы).
2. Тег версии без файла или файл без тега - жёлтое предупреждение, работа остаётся опубликованной.
3. Версию, тематику, группу фильтров с опубликованными работами удалить нельзя: нет «Видалити» и чекбокса;
   массовое удаление «всё или ничего» (`Нічого з вибраного не видалено. Заважає: X`, HTTP 409).
4. Фильтр только по формату → модалка открывается на новейшей версии с файлом этого формата. Выбор версии,
   которой нет в текущем формате, сам переключает формат; выбор формата версию не меняет.
5. Нет пары версия × формат → «This version isn't available in this format yet…» вместо Download.

## Гочи для тестирования

- prod-БД `godlike-wp-sql` смотрит в ПРОД, для stage не годится - данные stage только через UI.
- На stage в админке висят ошибки All-in-One WP Migration (права на каталоги) - шум окружения.
- Под админом каталог показывает те же счётчики, но поверх видна панель WP: скрины для демо снимать анонимно.
- Тематика у работы одна (radio): назначение временной тематики затирает исходную - запоминать её перед тестом.
