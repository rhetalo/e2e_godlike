# DEV-556 - Ошибки установки модов понятно в интерфейсе

> **В двух словах.** Бэкенд уже умел объяснять, почему мод или манифест не ставится, но пользователь этого не видел:
> старый дизайн показывал заглушку «Ключ ... не был установлен», модалка манифеста молчала, а окно «Some mods were
> disabled» всплывало на каждой странице. Теперь отказ показывается текстом бэкенда, модалка называет не вставшие
> файлы, а окно отключённых модов показывает список и не надоедает. Хвосты [DEV-492](DEV-492.md) F3, F7, F10.
> QA 23-Oct-2026 на проде: PASS.

## Что изменилось
- **Старый дизайн** (`useFlash`, panel!1689): нет перевода - показывается сам текст сообщения вместо заглушки. Касается
  всех flash старого дизайна, не только модов.
- **Тексты провайдера** (panel!1688): 404 и пустой `downloadUrl` (CF запретил сторонние загрузки) = «This file cannot be
  downloaded from the content provider: it no longer exists or is not available for download.» Сеть, таймаут, 400/401/403/429/5xx
  остаются «The content provider is temporarily unavailable». CurseForge и Modrinth одинаково, legacy и v2.
- **Валидация манифеста** (panel!1690): битые записи собираются в `invalidEntries`, а не роняют манифест целиком. Все записи
  битые - «No file entry in the manifest can be installed. <причина первой>».
- **Модалка манифеста** (new-panel!563): до установки - жёлтый блок «These entries are broken and will be skipped»; после отказа
  (409/400/500) или частичной установки модалка остаётся открытой с текстом и списком не вставших файлов, Proceed выключен
  (или Retry для `retryable`), Cancel → Close, тосты ошибок убраны.
- **Окно «Some mods were disabled»** (panel!1701 + new-panel!571): ответ несёт `revision`, `mods`, `unattributed_mods`; в окне
  список модов; «Got It» запоминается в `localStorage` до роста `revision`.

## Как это работает
- Отказы по ядру и лоадеру (409 `mods_not_supported` / `incompatible_mod_loader`, 400 в legacy) - только у серверов в раскатке
  [flag:extension-compatibility](../registry/flags.md#extension-compatibility) **по владельцу**. Вне раскатки legacy ставит
  моды на Paper как до DEV-515 ([DEV-556/F1](#находки)).
- `revision` = наибольший id неподтверждённых строк сервера. Растёт только при новом отключении; ручное включение мода
  убирает его из `mods`, но `revision` не меняет. Фронт сравнивает строго `>`.
- Ключ `localStorage`: `client-only-notice-dismissed:<server uuid>` = revision. При `pending: false` ключ стирается.
  `acknowledged_at` пишет только «Don't Show Again» (`POST .../client-only-notice/ack`).
- Аналитика: `modpack_setup_self_upload` уходит только при полностью успешной установке манифеста.
- API: [UP API: minecraft-mods](../products/up/api/minecraft-mods.md).
