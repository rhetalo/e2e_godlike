# DEV-513 - Устаревший образ в Параметрах запуска

> **В двух словах.** В старой панели после смены версии (или смены образа админом) страница
> «Параметры запуска» показывала старую Java, пока не нажмёшь F5. Клиент мог «вернуть» старую Java руками,
> и сервер переставал стартовать. Исправили: страница сразу показывает актуальный образ.
> QA 12-Oct-2026 на проде: клиентская часть и смена из админки, PASS.

## Что изменилось
- Заход в «Параметры запуска» через меню после смены версии показывает актуальный образ без F5.
- То же после смены образа админом или по API.
- Корректно переключается режим «Образ Docker этого сервера был установлен администратором» (`isCustomImage`)
  в обе стороны.

## Как это работает
- Причина (Jira): ответ `GET /api/client/servers/:uuid/startup` не содержал текущий образ; образ в стор писал
  только `getServer()` при монтировании всего `ServerRouter`, а переход по меню - клиентский роут без перемонтирования.
  Select образа был на `defaultValue`.
- Фикс сделан опцией 3 тикета: `/startup` теперь отдаёт `meta.docker_image`, существующий `mutate()` при заходе
  на страницу синхронизирует образ. Отдельного `getServer` при маунте нет.
- Фикс в core-коде панели, не в расширении versionchanger (патчи расширения теряются при `blueprint -upgrade`).
