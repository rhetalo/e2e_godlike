# DEV-405 - Источник модов, плагинов и сборок: прямые API CurseForge и Modrinth

> **В двух словах.** Раньше каталог модов, плагинов и сборок в новой панели брался из нашей
> собственной базы. Теперь для CurseForge и Modrinth список и версии берутся напрямую у этих
> сервисов, а в Installed появилась кнопка обновления мода. QA закрыто 05-Oct-2026: всё по задаче
> работает, один побочный дефект фильтров вынесен в [DEV-534](DEV-534.md).

## Что изменилось
- Mods / Plugins / Modpacks для провайдеров CurseForge и Modrinth читаются из live API провайдера,
  а не из таблицы каталога. Признак нового пути: CF total = 10000 (лимит API), было 10003 = count() таблицы.
- Своя библиотека остаётся для остальных провайдеров (Hangar, SpigotMC, Polymart, FTB, ATLauncher,
  Technic, VoidsWrath) и для полей `ram` / `is_optimized` у сборок.
- Новые фильтры каталога: Loader, MC version, Category, Author (Author скрыт на Modrinth).
- Новое: обновление установленного мода. `/mods/installed` отдаёт `update: {id, name}`, в grid-карточке
  Installed чип «Update available» и кнопка Update.
- Фильтры по умолчанию (пустые loader / mc_version) бэкенд подставляет значениями сервера (фикс п.1, 05-Oct).

## Как это работает
- Каталог: `GET /api/v2/servers/{uuid}/minecraft/{mods|plugins|modpacks}?provider=&search=&loader=&mc_version=&categories[]=&page=`.
- Версии: `/minecraft/{mods|plugins|modpacks}/{provider}-{id}/versions` - сырые файлы провайдера.
- Установка: `POST /minecraft/mods {provider, mod_id, version_id}`, удаление: `DELETE /minecraft/mods/{provider}-{id}`.
- Update на фронте не атомарный: DELETE старой версии, затем POST новой. Файл выбирается под loader и
  версию **сервера** (Storage Drawers forge-26.3.0.0 -> forge-26.3.0.1, а не более новый neoforge).
- Переключатель источника на проде включается по SSH (со слов разработчика). До ~14:30 30-Sep он был
  выключен, первый прогон 30-Sep шёл по БД.
- Глобальный middleware превращает пустую строку в null - из-за этого была проверка на `''` и корень бага
  DEV-405/B1 (со слов разработчика 30-Sep).
