# DEV-462 - Lifecycle подготовленных серверов в Pool Policies

> **В двух словах.** Доработки пула подготовленных серверов после DEV-429: выключенная сборка или политика не мешает
> выдавать уже готовые серверы, Rebuild пересобирает пул целиком, после смены модпака покупатель не получает сервер со
> старым модпаком, упавшие сборки освобождают сервер сами. QA: prod PASS 30-Oct-2026 на своих тестовых политиках
> с двумя покупками. Открыт один пункт: удаление failed-записей через 7 дней (проверка 06-Nov).

## Что изменилось
Отдельного MR с ключом DEV-462 нет, доработки шли MR-ами DEV-429:
- [panel!1567](https://git.godlike.ovh/panel/panel-godlike-host/-/merge_requests/1567): `findMatch()` без фильтра `enabled` (выключенная политика продолжает продавать), Rebuild после удаления сразу диспатчит `ReconcilePreparedServerPoolJob`, честный флеш, когда замен не будет.
- [panel!1583](https://git.godlike.ovh/panel/panel-godlike-host/-/merge_requests/1583): Reinstall modpack снова пишет `eula.txt`; `ReclaimFailedPreparedServerAction` на часовом тике освобождает сервер failed-строки через `PREPARED_SERVERS_FAILED_SERVER_RETENTION_MINUTES` (15), запись живёт 7 дней; консольный лог в момент падения.
- [panel!1608](https://git.godlike.ovh/panel/panel-godlike-host/-/merge_requests/1608): выдача сверяет provider / modpack / version строки, Reinstall передаёт полную идентичность политики, тик лечит дрейф и у выключенных политик.
- Позже рядом: [panel!1703](https://git.godlike.ovh/panel/panel-godlike-host/-/merge_requests/1703) (crash breaker, DEV-590), [panel!1714](https://git.godlike.ovh/panel/panel-godlike-host/-/merge_requests/1714) (tier drift → rebuild на тике).
