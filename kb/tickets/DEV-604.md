# DEV-604 - тарифы видны AI-ботам

> **В двух словах.** Блок тарифов на страницах игр рисовал только Vue, а AI-боты (GPTBot, ClaudeBot, PerplexityBot) JS не
> выполняют и цен Godlike не видели. Теперь сервер отдаёт карточки тарифов текстом внутри Vue-контейнера (название, слоты · RAM,
> цена со скидкой, обычная цена, Add to Cart), а JSON-LD страницы - один `ProductGroup`, где каждый тариф вариант со своей ценой и
> ссылкой `?plan=<id>`. Для посетителя с JS блок прежний. QA: PASS, prod, три раунда 02-04 Nov 2026.

## Что изменилось
- [wp!750](https://git.godlike.ovh/wp/godlike-host/-/merge_requests/750) (28-Oct): серверная разметка карточек
  (`template-parts/storefront/game-tariffs-ssr.php`, `inc/tariffs-ssr.php`), цена считается PHP по формуле Vue; `main.js` монтирует
  Vue после загрузки чанка, без пустого кадра; JSON-LD Offer = цена карточки, без Custom. Годовые лендинги и cart-секции без разметки.
- [wp!751](https://git.godlike.ovh/wp/godlike-host/-/merge_requests/751) (29-Oct): Add to Cart в серверной карточке - `href="#"` +
  `data-cart-url` + `onclick`, чтобы краулеры не ходили в корзину.
- [wp!755](https://git.godlike.ovh/wp/godlike-host/-/merge_requests/755) (03-Nov): `inc/tariffs-schema.php` - один `ProductGroup` на
  страницу (вариант = тариф, `sku` = id тарифа, `offers.url` = `?plan=<sku>`, `shippingDetails` 0 дней / 50 стран), рейтинг и отзывы
  на группе, даты акции только для глобальной; страница со своим Product в Schema JSON группу не получает. Vue подсвечивает и
  прокручивает к карточке по `?plan=`. `MerchantReturnPolicy` подготовлена, но закомментирована до согласования.
- [wp!783](https://git.godlike.ovh/wp/godlike-host/-/merge_requests/783) (04-Nov): подписи 9 игр в `glr_theme_game_labels()`
  (F3), у персональной акции нет «Ends <дата>» в тексте карточки (OBS-2), формат даты из Polylang-строки `F j, Y H:i`.

## Не баг - так задумано
- Валюта серверной разметки гео (по IP), а не USD как в описании; бот из США получает USD.
- Ссылка корзины в серверной карточке без `location` (её добавляет только Vue).
- Страницы модпаков без цены (и с JS тоже) - вне требований.
- Подсветка по `?plan=` выглядит как «Most Popular»: рядом с популярной картой рамок может быть две.

## Регресс
**candidate**, read-only, без браузера: запрос страниц игр с User-Agent GPTBot и `currencyId=1; currency_manual=1`, разбор HTML.
- 7 игр: серверные карточки есть, у платных цена и `data-cart-url`, у Custom нет; `href="/cart` в блоке нет.
- ровно один `ProductGroup`, варианты = платные карточки (имя = имя группы + тариф + «Plan», цена, валюта, `?plan=<sku>`), без `priceValidUntil`.
- опционально UI: `?plan=<sku>` подсвечивает карточку (Vue, через `GameStorefrontPage`).
Нужен хелпер-парсер в `utils/` и спек в `tests/general/` - предложено владельцу отдельным шагом. Акцию не автоматизировать: у UA/PL
её нет, гео определяется по IP.
