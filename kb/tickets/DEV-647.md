# DEV-647 - страница RuneScape: Dragonwilds

> **В двух словах.** Новая игровая страница [godlike.host/runescape-dragonwilds-server-hosting](https://godlike.host/runescape-dragonwilds-server-hosting/)
> на стандартном шаблоне (эпик MAR-501, релиз 12.11). Три тарифа Wanderer / Adventurer / Dragon Slayer + Custom.
> QA на проде 10-12 Nov: PASS с замечанием по слотам. Пара к тарифам - [DEV-648](DEV-648.md).

## Как работает
- Шаблон `storefront`: Hero + CTA, тарифы (Budget, кнопка Add to Cart → `/cart?productId=<pid>&billingCycle=monthly&promo=VANILLA20...`), FAQ, SEO-блоки.
- CTA: Wanderer → 1219, Adventurer → 1221, Dragon Slayer → 1223; Customize server открывает конфигуратор на странице.
- Цены берутся из WHMCS по гео-валюте, первая покупка -20% (VANILLA20).
- Каталог `/game-servers-en/` и меню Game servers: игру добавляют после QA (решение владельца).

## Итог QA
- PASS: блоки AC, цены = WHMCS (все 21 валюта, циклы 1/3/6/12), CTA, SEO (title, description, canonical, H1-H3, sitemap), адаптив 375/768/1280, GA4 (page_view + Add_to_cart без дублей).
- Общие для всех игр вещи (старая воронка корзины, TypeError темы, кросс-браузер) в отчёт не шли - память feedback-new-game-qa-scope.

## Находки
- **DEV-647/F1** (Medium, открыт, решение) На странице 2/4/6 слотов, на сервере `MAX_PLAYERS` 1..6 на любом тарифе, в WHMCS «Slots are unlimited». Общий с DEV-648.
- **DEV-647/F3** (Low, открыт, найден при закрытии 12-Nov) JSON-LD `ProductGroup.name` = «Runescape Dragonwilds Server Hosting» (собран из адреса), а не подпись игры. Как alt:V до wp!783 ([DEV-604](DEV-604.md)).
- **DEV-647/OBS-2** (Low) `og:image` = дефолтная картинка темы.

## Регресс
