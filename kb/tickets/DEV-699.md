# DEV-699 - Скрыть субдомены для игр, которые их не поддерживают

> **В двух словах.** На странице Port & Domains блок «Update Subdomain» раньше видели все игры, кроме GTA, хотя домены
> выдаются только Minecraft и Hytale. Теперь блок показывается только им, остальным он скрыт, а порты занимают всю
> ширину. QA на проде просмотром - PASS. Попутно нашли, что Minecraft-сборки FTB и Quilt забыты в настройке доменов
> (блок есть, список пуст) - L2 поправили данными в тот же день, ретест PASS.

## Что изменилось

- Блок «Update Subdomain» на `/server/{uuid}/network` показывается, только если `nest_id = 1` (Minecraft) или `egg_id = 2068` (Hytale).
- Для остальных игр блок скрыт целиком, сетка переключается в одну колонку (`.server__overview-block__full`) - как раньше для GTA.
- Free-серверы Minecraft без изменений: блок виден и размыт.
- Правило - чистая функция `supportsSubdomains` (`src/helpers/serverGame.ts`), во фронте `hasSubdomainSupport` из `useCurrentServer()`. Бэкенд не менялся.

## Как это работает

- Видимость блока - фронт, по `nest_id` / `egg_id` сервера.
- Список доменов в селекте - бэкенд: `GET /api/v2/servers/{uuid}/subdomains` отдаёт домены из таблицы `domains`, у которых
  `egg_ids` содержит egg сервера и `free` совпадает с `server.free` ([API](../products/up/api/subdomains.md)).
- Настройка доменов (какие eggs, протокол SRV `_minecraft`, тип `tcp`/`udp`/`none`) - данные в панели `/admin → Subdomains`, правят L2/админы, без деплоя.
- Смена egg на тот, которого нет в домене, **удаляет** выданный субдомен (`panel` `app/Listeners/Server/ServerEventSubscriber.php:139`, по коду, вживую не проверяли).
