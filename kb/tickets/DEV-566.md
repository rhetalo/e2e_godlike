# DEV-566 - Каталог Minecraft-схематик

> **В двух словах.** На сайте появился каталог схематик (готовых построек для Minecraft) `/minecraft-schematics/`:
> подборки по тематикам, поиск, фильтры по версии и формату, карточка с превью и бесплатное скачивание файла.
> Контент ведёт контент-менеджер в WP-админке. QA на stage 20-Oct (v1-v5), ретест wp!719 21-Oct и wp!723 22-Oct:
> PASS, открытых замечаний нет.

## Что изменилось
- Новый тип записи `schematic`, таксономии `schematic_category` (тематики), `schematic_version`, `schematic_format`,
  `schematic_filter` (свои группы фильтров, 2 уровня), поля Carbon Fields «файл + версии».
- Страница `/minecraft-schematics/`, модалка `?schematic=<slug>`, эндпоинт скачивания
  `/?gl_schematic_file=<id>&version=<slug>&format=<ext>`. Подробно: [WPGL/schematics](../products/wpgl/schematics.md).
- wp!719 (21-Oct): правки по отчёту v5 - уведомления (F1), порядок терминов (F6), JS Carbon (F9), защита версии (F11),
  массовое удаление «всё или ничего» (F7), автопереключение формата в модалке (OBS-5).

## Итог QA
- **20-Oct, stage, v1-v5:** DoD PASS (Chromium, Firefox, WebKit, 1440 / 768 / 375 / 360), Figma PASS, 11 Low.
  Скачанные файлы побайтно совпали с загруженными. Артефакт v5 `art:YBED46KftrXvRQaoN56LAi`.
- **21-Oct, stage, ретест wp!719:** 8 из 9 шагов MR PASS, шаг 2 PASS с замечанием R-1. Регресс Chromium, Firefox, WebKit PASS.
  Финальный demo-артефакт `art:WdFR7knyCxzfwuiAiDiJgg` (исходник `test-docs/godlike.host/DEV-566/final/`).
- **22-Oct, stage, ретест wp!723 (R-1):** 4 из 4 шагов PASS - «Порядок» ↓ ровно обратный ↑ в Версіях, Тематиках, Форматах;
  «Назва» по алфавиту в обе стороны; порядок на сайте прежний. Артефакт обновлён (v2).
- Права ролей живьём не проверялись (решение владельца), только по коду.
