# DEV-562 - Steam Port для Project Zomboid в Overview

> **В двух словах.** Чтобы подключиться к серверу Project Zomboid, игроку нужен второй порт - Steam Port. Теперь он
> показан в карточке Server Information под адресом сервера, и его можно скопировать одной кнопкой. Если порт
> настроен неправильно, строка просто не показывается. QA 15-Oct-2026 на проде: PASS, багов по задаче нет.

## Что изменилось
- В `GET /api/v2/servers/{id}` новое поле `steam_port` (число или null).
- В Overview -> Server Information строка «Steam Port» (`[data-test="steam-port"]`) с кнопкой копирования и тостом
  «Steam port successfully copied». Domain/IP при этом остаётся с основным портом.
- Только для egg из `PROJECT_ZOMBOID_EGG_IDS`. Другие игры (Arma 3, Minecraft, Rust, ARK) - null, строки нет.
- Переводов ключей Server.Steam_Port* пока нет: в RU английский fallback, сырого ключа нет.

## Как это работает
- Значение из переменной сервера `STEAM_PORT` (дефолт 66 ❓ - так записано в памяти, смысл дефолта не уточнён).
- Валидация бэкенда: 1024-65535, без ведущих нулей, не равен основному порту, порт - allocation этого же сервера на той же
  ноде и IP. Иначе `steam_port = null` и строки нет.
- Игра определяется по egg, а не по наличию переменной (Arma 3 со своим `STEAM_PORT` -> null).
