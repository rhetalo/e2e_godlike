# DEV-659 - Del from the old node и живой сервер

> **В двух словах.** После A→B→A без удаления копии кнопка «Del from the old node» удаляла сервер на ноде, где он
> работает, и забирала его порты. Фикс: такая запись только закрывается, порты освобождаются только свои,
> сначала удаление в Wings (404 = успех), при ошибке ничего не трогается; у Del и Rollback confirm.
> Доделка !1774: повторный Del без копий пишет «nothing to delete». QA закрыт 06-Nov-2026, prod PASS.

## Что изменилось

- [panel!1765](https://git.godlike.ovh/panel/panel-godlike-host/-/merge_requests/1765) (прод 05-Nov-2026 08:58 UTC):
  - `DELETE /admin/servers/view/{id}/manage/transfer/rollback` (Del): запись с `old_node = server.node_id` - только `deleted_from_old_node_at`; иначе Wings delete → `releaseServerOwnedAllocations` → закрытие; ошибка Wings → алерт «could not be deleted from N old node(s)».
  - `POST .../transfer/rollback` (Rollback): не берёт записи с `old_node` = текущей ноде; отвязывает только свои новые порты; после удаления копии закрывает записи, где эта нода старая.
  - Blade: `canRollback` и `canDeleteFromOldNode` раздельно, `onsubmit="return confirm(...)"`.
- [panel!1774](https://git.godlike.ovh/panel/panel-godlike-host/-/merge_requests/1774) (прод 05-Nov-2026 15:05 UTC, билд `eecd14d8`):
  если ни одна копия не удалена - синее info «No server files left on the old node, nothing to delete.» вместо зелёного «Server files deleted from the old node.». Только бэкенд.
