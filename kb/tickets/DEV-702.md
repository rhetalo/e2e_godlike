# DEV-702 - LinkUserToServerActionTest снова зелёный (id сервера + мок контракта ролей)

> **В двух словах.** С [DEV-667](DEV-667.md) `LinkUserToServerAction` вызывает `isAssignableOnServer($serverRoleId, $server->id)`,
> а тест создавал сервер через `Server::factory()->make()` без id → 2 из 3 тестов падали с `TypeError ... null given`.
> До [DEV-642](DEV-642.md) это пряталось за ParseError mockery 1.6.12. Починили сам тест, код панели не менялся.
> QA: PASS 11-Nov-2026 по статике через GitLab API; PHPUnit прогнал разработчик (у QA нет PHP).

## Что изменилось
- [panel!1794](https://git.godlike.ovh/panel/panel-godlike-host/-/merge_requests/1794) (merged 10-Nov, merge 9d708b46), только
  `tests/Unit/Services/Sharing/LinkUserToServerActionTest.php`:
  - в двух тестах задан `$server->id = 3`;
  - анонимная заглушка `ServerRoleRepository` (всегда `true`) → `m::mock(ServerRoleRepositoryContract)`, ожидание
    `isAssignableOnServer(7, 3)`; в тесте владельца `shouldNotReceive('isAssignableOnServer')`;
  - удалён ошибочный комментарий «Mockery cannot generate the contract (a `static` return type)».
- На прод не влияет, миграций нет.
