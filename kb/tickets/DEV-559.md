# DEV-559 - клиентские моды Forge и NeoForge отключаются на сервере

> **В двух словах.** Раньше сканер знал сторону мода только у Fabric, а любой Forge/NeoForge jar считал безопасным,
> и клиентский мод вроде Controlling оставался на сервере. Теперь сканер читает `mods.toml` / `neoforge.mods.toml`
> и байткод `@Mod`, такие моды на старте уходят в `*.jar.disabled`. QA 29-Oct-2026 на проде: PASS по шагам MR и DoD,
> один граничный случай с Sodium вынесен на обсуждение (K1).

## Что изменилось
- Сигналы клиентского мода (parser v8, 22-23 Oct, mod-scan-service !8-!13): `clientSideOnly=true`, зависимость на
  `minecraft` / `forge` / `neoforge` с `side="CLIENT"` (только у jar без игрового контента), байткод `@Mod clientSideOnly=true`
  (Forge, работает и для legacy 1.12.2 с `mcmod.info`). NeoForge `@Mod(dist=CLIENT)` и `displayTest` - только информация.
- [mod-scan-service!14](https://git.godlike.ovh/panel/mod-scan-service/-/merge_requests/14) (28-Oct): `provides` из `[[mods]]`
  попадает в запись (Sodium NeoForge → `indium`), `ParserVersion` 8 → 9, golden-тест `TestRealWorldManifests` на 9 манифестах.
- Включено флагом панели `mod-scan-side-detection-enforce` (everyone с 26-Oct-2026 08:59), без флага правила работают в режиме observe.
- Каскад-гард панели (04570dcff): Forge/NeoForge breaking-мод, который жёстко требует включённый мод (по `mod_id`/`provides`),
  не отключается, а ранее отключённый сканером возвращается в `.jar`; запись об отключении при этом удаляется.

## Гочи для тестирования
- Каталог модов - `/server/{uuid}/extensions`; прямой `/minecraft/mods` даёт пустую страницу. Сервер открывать по полному UUID.
- Controlling, Sodium, Flywheel, CTM в каталоге скрыты: ставить `POST /servers/{uuid}/minecraft/mods {provider, mod_id, version_id}`.
  CF Controlling: Forge 1.20.1 12.0.2 = 4646682, NeoForge 1.21.1 19.0.5 = 6368976, Forge 1.12.2 3.0.12.4 = 5408385;
  Sodium NeoForge 0.8.13 = 8756580 (проект 394468).
- Известный jar новых строк в `minecraft_mod_scan_results` не даёт (дедуп по хешу). Запись отключения - `server_client_only_mod_overrides`
  (`filename` + `hash`) → join по `hash`. Время в panel DB - UTC.
- После вайпа первый Start упирается в EULA; сканер к этому моменту уже отработал. Смена ядра с вайпом спрашивает «Save your world first?».
- Окно «Some mods were disabled» модальное, перекрывает Shut Down.
