# DEV-651 - Онбординг первого запуска

> **В двух словах.** Новый сервер при первом открытии показывает попап «что установить»: модпак из каталога
> (по умолчанию только те, что тянет тариф), Java с выбором ядра и версии или Bedrock. Одна кнопка Install,
> прогресс по этапам, в конце Download Launcher. QA на проде 12-Nov через Force-enable: Java, Bedrock, RAM-фильтр,
> Upgrade, админ-карточка PASS. Всё устанавливается, включая модпаки; два замечания к окну установки (F5, F2), обе у разработчика.

## Как работает
- Таблица `server_setup_onboardings`: `is_eligible`, `is_force_enabled`, `shown_at`, `configured_at`.
  Пул-серверы (`prepared-*`) получают строку с `is_eligible=0` и `configured_at`.
- Право на онбординг: Pennant-флаг [flag:first-launch-onboarding](../registry/flags.md#first-launch-onboarding) у владельца +
  сервер создан после `FIRST_LAUNCH_ONBOARDING_MIN_CREATED_AT` (default 2026-11-16), автопоказ не старше
  `AUTO_SHOW_MAX_AGE_DAYS=7`. Force-enable в админке сервера снимает проверки даты и возраста.
- API: [UP/api/setup-onboarding](../products/up/api/setup-onboarding.md). Модпак из попапа ставится с
  `setup_onboarding:true` и обходит проверку ядра (panel!1799), см. [UP/api/modpacks](../products/up/api/modpacks.md).
- Каталог в попапе: `ram_aware`, `max_ram_mb`; пак проходит, если `GREATEST(COALESCE(recommended_ram_mb,4096),4096) <= max_ram_mb`.
  На 2 GB не подходит ни один (by design), фронт показывает все с плашкой (new-panel!623).
- UI: автопоказ один раз, потом кнопка «Set up server» на Overview и «Set Up» / «Not set up» в списке серверов
  (`data-testid="setup-row-action-button"`). `?setup=1` открывает попап и на настроенном сервере.
- Админка: `/server/<id>/admin`, карточка «First-launch Setup Onboarding» (Enabled, Admin override, Popup shown, Configured).

## Итог QA (12-Nov, prod)
- PASS: DoD 1, 3-8, 12; panel!1799 (модпак поверх Paper без 409); new-panel!619, !623, !625, !626; XSS в поиске; Cancel в подтверждении.
- DoD 9 частично: установки доходят до конца, замечания к окну (F5, F2). DoD 13 частично (F5, OBS-2). DoD 10-11 (экран ошибки) не достигнуты, сабюзер и GA4 не проверены.
- Ложная находка F3 (Java «ready» при упавшем сервере) снята: не была принята стандартная EULA-модалка ([UP/modals](../products/up/modals.md)).

## Находки
- **DEV-651/F5** (Minor, у разработчика) Модпак ставится до конца (`server_modpacks`, Fabric, `servers.status` null), но попап
  закрывается на первых процентах: нет этапов и «ready», `install_completed` не уходит. 3 сервера, 2 аккаунта.
- **DEV-651/F2** (Minor, у разработчика) Прогресс «Setting up your server» считает (13% → 91%) под окном «Replace Server Files?»
  до подтверждения. Связана с F5: та же логика окна установки, после подтверждения панель блокируется и открывает
  отдельное окно. Передана вместе с F5.
- **DEV-651/OBS-1** Визуальный шум: рядом с попапом висит Roadmap V2 «New to hosting? / Get 3 Free Days».
- **DEV-651/OBS-2** `launcher_download_clicked` и `onboarding_shown` без `option`.
- Снято владельцем: F1 (на 2 GB при повторном открытии «No modpacks found») - by design.

## Гочи для следующего раза
- Автопоказ «по правилам» до отсечки не проверить: только Force-enable в админке.
- После установки версии панель стартует сервер и показывает EULA-модалку: принять, не уходить со страницы.
- RAM сервера меняли в legacy-админке `/admin/servers/view/<id>/build` (поле memory).

## Регресс
**blocked**: фича под флагом (4 пользователя) и до отсечки видна только с Force-enable. После раскатки на всех:
read-only спек на тест-аккаунте - кнопка «Set Up» в списке, `?setup=1` открывает попап с тремя вариантами, пилюля RAM,
Modpacks с `ram_aware`, контракт `GET setup-onboarding` (zod). Установки из попапа - мутация, только на `test_e2e_mut-*`.
