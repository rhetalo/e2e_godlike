# DEV-506 - Откат версии Arclight после установки

> **В двух словах.** Пользователь ставил ядро Arclight 1.21.1 или 1.20.1, а панель после перезагрузки показывала
> 1.21 или 1.20: у разных версий есть билды с одинаковыми именами, и панель находила не тот. Фикс на бэкенде это
> исправил. QA 05-Oct-2026: сценарий тикета PASS, но тот же класс ошибки нашёлся при запуске сервера и вынесен в [DEV-529](DEV-529.md).

## Что изменилось
- Install Arclight 1.21.1 / 1.20.1 (по умолчанию и не по умолчанию) после reload держит выбранную версию и id билда.
- Быстрая переустановка 1.21.1 -> 1.21 -> 1.21.1: каждый шаг свой id.
- Другие ядра с дублями имён билдов (Fabric, Quilt, Paper, Canvas, Folia, Leaves, Sponge, Mohist) тоже держат свой id.
- Каталог не объединяли (у 1.21 и 1.21.1 по 632 билда), фикс на бэкенде.

## Как это работает
- Смена ядра: Versions -> карточка -> версия -> Select Build -> Install, `POST /minecraft/versions/install {build, delete_files}`.
- Состояние: `GET /minecraft/version` (тип/версия сервера) и `GET /minecraft/versions/installed` (установленный билд, `latest`).
- `/versions/installed` определяет билд «по файлам»; для Arclight forge/neoforge он видит библиотеки Forge/NeoForge
  внутри Arclight и после старта перезаписывал `/minecraft/version` (это и есть DEV-506/F1).
- Install с Wipe показывает окно «Save your world first?» (World Backup); «Continue without backup» шлёт `delete_files:true`.
