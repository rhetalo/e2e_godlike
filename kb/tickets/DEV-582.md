# DEV-582 - Зависшие PENDING бэкапы → FAILED

> **В двух словах.** Бэкап, на который Wings не ответил, навсегда оставался PENDING и занимал слот. Теперь раз в 30 минут
> команда переводит такие бэкапы старше 6 часов в FAILED, и слот освобождается. Старая проба, которая писала фальшивые
> COMPLETED, удалена, статусы старых строк выровнены миграцией. QA: prod PASS 27-Oct-2026 по read-only SQL.

## Что изменилось
- `panel!1713` (prod 27-Oct-2026 09:21 UTC, build `749df565`):
  - команда `gl:backups:fail-stale-pending` (`--dry-run`, `--prune-age`), `everyThirtyMinutes` + `withoutOverlapping(30)`, включена при
    `config('backups.prune_age')` (360 мин);
  - фильтр: `status = PENDING`, `completed_at IS NULL`, `schedule = 0`, `updated_at` старше порога; ставит `FAILED`, `is_successful = 0`, `completed_at = now`;
    таблицы `backup_instances`, `backup_folders`, `backup_databases`;
  - миграция `2026_10_26_120000_backfill_status_of_completed_backups` - `status` по `is_successful`;
  - удалены `ResolvePendingBackups` (`gl:resolve-pending-backups`), `BackupCompletionWorkflow` и переключатели в админке Durable Workflow
    («Backup completion watchdog», «Backup callback deadline»).

## Итог QA
