# DEV-476 - Поиск файлов без долгих запросов

> **В двух словах.** Поиск по файлам сервера раньше на большом модпаке шёл до 125 с и держал PHP-FPM воркер.
> Теперь ответ идёт потоком: первые совпадения через 0,7 с, весь модпак (5003 файла) за 5,8 с. Добавлены
> лимиты: минимум 2 символа, 500 совпадений, не больше 2 поисков на пользователя. QA 20-Oct-2026 на проде:
> PASS, одно Low-пожелание.

## Что изменилось
- `GET /api/v2/servers/{uuid}/files/search` отдаёт `text/event-stream`: кадры `match` / `progress` / `end`.
  Подробно - [API files](../products/up/api/files.md).
- Лимиты: запрос от 2 символов (иначе 422), 500 совпадений, 1500 листингов папок, дедлайн 15 с.
- Защита от параллели: 2 поиска на пользователя и 4 на ноду (третий - 429 до открытия стрима), throttle 20 запросов в минуту.
- При обрыве клиентом воркер останавливается, слот освобождается через ~0,3 с.
- Страница Config определяет иконку сервера одним `GET files?dir=/`, без `/files/search` и `/server-icon.png`.

## Итог QA

- Шаги MR 1-8 PASS: скорость, клик по результату открывает файл из его подпапки, 1 символ (UI не шлёт, API 422), стирание до 1 символа
  возвращает папку, третий поиск 429, обрезка на 500 (`truncated/matches`, баннер «Too many matches…»), Config без поиска, обрыв клиентом.
- Свои проверки: выдача сверена с полным деревом сервера, 11 из 11 выборок 1:1 (регистр, подпапки, пусто, 357 / 442 / 498 совпадений),
  корзина в выдачу не попадает; 21-й запрос в минуту - 429 «Too Many Attempts.»; без токена 401, чужой uuid 400, `dir=/../../` за корень не выводит;
  имя файла без `v-html`.
- Не проверено: Graylog `event=file_search` (нет доступа), Wings 500 на отдельных папках (на проде не вызвать, покрыто юнит-тестами MR),
  иконка на сервере с иконкой, сабюзер без прав на файлы. Лаунчер отложен владельцем.
