# DEV-586 - Один тост при отказе в бэкапе

> **В двух словах.** Раньше на второй бэкап в течение часа панель показывала два красных тоста («Request failed with status
> code 429» и текст сервера) и не говорила, когда можно повторить. Теперь 429 несёт `retry_after`, а панель показывает один тост
> «Backup limit reached for this server. Please try again in N minutes». Отказ «нет слотов» тоже больше не двоится.
> Саббага [DEV-484/OBS-1](DEV-484.md#находки). QA: stage PASS и prod PASS 27-Oct-2026.

## Что изменилось
- **Бэкенд** `panel!1708` (prod 26-Oct-2026): ответ 429 на создание бэкапа (`BackupCreationFailedResponse`) несёт
  `error_code: backup_throttled`, `retry_after` (секунды) и заголовок `Retry-After` с тем же значением.
- **Фронт** `new-panel!574` (prod 27-Oct-2026): запросы создания бэкапа идут с `suppressErrorNotifications: true`, глобальный тост
  axios не показывается. `onError` мутации показывает один тост через `backupCreateErrorText`: минуты округляются вверх,
  `retry_after ≤ 60` → «in a minute», `retry_after: null` → текст «обратитесь в саппорт». Остальные ошибки (400 слоты, 422) - текст сервера одним тостом.
- Деплой фронта на prod задержался: pipeline main #24425 упал на type-check (vue-tsc Killed, OOM раннера), deploy_to_main skipped;
  после перезапуска 27-Oct-2026 сборка `index-9VCFS_WN.js`.
