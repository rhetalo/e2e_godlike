# DEV-549 - туториал и «Upload custom modpack» по ядру сервера

> **В двух словах.** Добивка [DEV-515](DEV-515.md). Туториал на вкладках Mods / Modpacks / Plugins строит шаги из
> возможностей ядра и больше не падает на заглушках. Кнопка «Upload custom modpack» в File Manager на ядрах без
> модпаков стала контурной, неактивной и с тултипом. API перестал называть платформу плагинов, если плагины запрещены.
> QA 19-Oct-2026: PASS.

## Что изменилось
- **Туториал** (`modsTourSteps(capabilities, tab)`, new-panel!549):
  - моды поддерживаются (Forge, Fabric, NeoForge, Quilt, гибриды) или флага нет - прежние 7 шагов
    (intro → modpacks → mods types / search / install → FM custom modpack → FM upload);
  - модовое ядро, запуск с Plugins - первым шаг `step-mods-plugins-mods-only` («плагины недоступны, моды поддерживаются»), всего 8;
  - Paper-подобные - тур плагинов: `step-mods-plugins-intro` → шаг на заглушке вкладки запуска (если Mods / Modpacks)
    → Plugins types / search / install (вкладка открывается сама) → FM upload. 6 шагов с Mods/Modpacks, 5 с Plugins;
  - Vanilla - один шаг с текстом вкладки, «1 of 1», End Tutorial, в FM не уводит.
  - Тур стартует, когда capabilities загружены; переходы явные, без `router.back()`; клавиатурная навигация Shepherd выключена.
  - Тур первого захода в File Manager не стартует, если активен другой Shepherd-тур, и не помечается показанным.
- **Кнопка** `.server__file-manager__custom-modpack-btn`: при `supports_modpacks:false` - `variant=outlined`, цвет `#ff784d`,
  `disabled`, opacity 0.6; тултип вешается на обёртку `span[tabindex=0]` (hover + фокус). Иначе прежняя заливка.
- **API** (panel!1670): `extension_capabilities.plugin_loader = null` и `plugin_providers = []`, если `supports_plugins:false`.
- 17 новых ключей `Server_Extensions.Tour.*` + `Server_Extensions.Unsupported.Custom_Modpack_Upload` во всех 17 локалях.

## Регресс
**candidate**, read-only, приоритет 4. На ядре без модпаков кнопка «Upload custom modpack» в File Manager disabled
с тултипом; `extension_capabilities.plugin_loader = null` и `plugin_providers = []` при `supports_plugins:false`. Нужны два
сервера на разных ядрах (Paper-подобное и модовое) из реестра. Туториал Shepherd в регресс не берём - хрупкий и меняется.
