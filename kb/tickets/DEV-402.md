# DEV-402 - Страницы игр подключены к новой воронке

> **В двух словах.** Раньше с карточки игры покупатель попадал в общую корзину и искал игру заново.
> Теперь клик по игре открывает новую воронку (собрана на базе `modded new`, без логики модпаков)
> с уже выбранной игрой и самым дешёвым тарифом. Отдельного QA-прогона по AC не было: 20-Aug-2026
> выкатка сломала ~90 автотестов, тимлид переписал воронку в тестах под новый карт, прогон стал зелёным.

## Что изменилось
По Jira (ТЗ, Олексій):
- Основная кнопка / картинка игры на `/game-servers-en/` и страницах игр через JS открывает новую воронку,
  игра передаётся автоматически и сохраняется на всех шагах.
- По умолчанию ставится самый дешёвый тариф; тип сервера / пресет выбирается в воронке (как на главной).
- Показываются только тарифы и локации, доступные для игры. USA-локации не показываются USA-юзерам (так в ТЗ ❓ формулировка).
- Промо-логика та же, что в действующей новой воронке: 75% на месячную оплату во время акции, после акции
  стандартные скидки по периодам. Отдельной ценовой логики нет.
- После авторизации сохраняются игра, число игроков, тариф, локация, промокод.

## Как это работает
Только то, что видно из перестройки автотестов (тимлид, `gitlab/main c19b809`, 20-Aug):
- Лендинг игры открывается прямым URL из `games.json.landing`; тарифы игры за новым картом
  `/cart-game-servers/?productId=`.
- Промо-вердикт берётся из ответа бэка (`promoVerdict()` в тестах).
- Блок авторизации: `.auth-block` → `.auth-page` (`auth-page__tab/__form`, `form__button--primary`,
  `social-button--google/discord/twitch/apple`), тот же компонент, что в мобильной корзине.
- Старая сетка `.storefront__tariff` удалена; каталог игр в mega-menu `header-menu__subitem-game`.
