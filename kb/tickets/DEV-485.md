# DEV-485 - Гейт старта по Java

> **В двух словах.** Раньше сервер на слишком старой Java сначала запускался и падал, а подсказку видел
> только тот, у кого открыта панель. Теперь бэкенд проверяет Java до старта и вообще не запускает сервер:
> кнопки Start / Restart, API и расписание получают отказ, клиент видит понятное окно или тост.
> QA 25-Sep - 09-Oct-2026: гейт работает на всех путях. Хвосты: письмо, лаунчер, DoD «строка в консоли».

## Что изменилось
- Блок только «слишком старой» Java (нижняя граница надёжна, верхняя эвристична и сломала бы Forge 1.16-).
- Start в панели: отказ через полинг `server-jar/status` (`status=failed`, `error=java_too_old`) + диалог с предвыбранной Java.
- `POST /api/v2/servers/{uuid}/power` start / restart → 409 `{"error":"java_too_old","required_java":N,"current_java":M}`.
- Планировщик (`POST tasks/run` power start) не стартует сервер.
- Restart кнопкой работающего сервера со сменённым образом → 409, сервер продолжает работать (new-panel!548).
- Принятие EULA теперь идёт через `POST /power restart` (тоже под гейтом).
- По DoD «сообщение в консоль» заменено тостом / диалогом / 409 - ❓ нужно согласие продукта.

## Как это работает
- Флаг [flag:java-start-gate](../registry/flags.md#java-start-gate): изначально per-user, но фоновая задача `ensure`
  без пользователя читала `__laravel_null=false` → гейт не срабатывал. Переделан на **per-server** (panel!1640):
  на 07-Oct `Server|771938=true`, глобально false.
- Start в новой панели идёт не через `/power`, а через `POST minecraft/server-jar/ensure` (202 `checking`, старт в фоне).
- Restart на выключенном сервере = start, гейтится безусловно (API, лаунчер, расписание).
- `kill` не блокируется. Java новее нужной не блокируется.
- Автодетект выключен → `ensure` 202 `{"status":"failed","error":"java_too_old","skipped":"server_toggle"}`.
- Уведомления: только email и только для фоновых путей (1/час); `user_notifications` не пишутся by design.
- Теневой режим (флаг выкл) пишет только в файловый лог Laravel.

## Хвосты
- Письмо владельцу при блоке фонового старта: нужен сервер с живой / одноразовой почтой + флаг на сервер (просить разраба).
- Restart без подтверждения (`user.restart_confirmation=false`) - настройка аккаунта, не менялась; по коду тот же путь.
- Лаунчер и не-Minecraft (Hytale) - скип владельцем.
- Решение продукта по DoD «строка в консоли».
- Гоча: краш на Java 8 быстрее опроса `/resources` - доказывать по строкам консоли; рестарт Fabric - по сбросу uptime.
