# DEV-630 - Windrose в игровой панели

> **В двух словах.** Новую игру Windrose (эпик MAR-496) подключили к ultra.panel через egg 2104 (Proton + steamcmd,
> Steam AppID 4129620). После покупки сервер сам ставится, стартует и регистрируется у бэкенда игры; игроки входят
> по инвайт-коду. QA на проде 10-Nov, ретест 12-Nov: PASS с двумя Low-остатками (подсказка Region, карточка тарифа).

## Как работает
- egg **2104 «Windrose»**, образ `ghcr.io/ptero-eggs/steamcmd` (Proton). Старый egg 2088 «Windrose TEST» (wine) остался в БД, к тарифам не привязан.
- Тарифы WHMCS 1225-1230 (группы 196/197: Deckhand / Archipelago / Pirate Legend, 8/12/16 GB) → egg 2104 в `configoption8`.
  Витрина: [godlike.host/windrose-server-hosting](https://godlike.host/windrose-server-hosting/) (4/6/8 слотов).
- Переменные (10 видимых): Server Name, Use Direct Connection, Password Protected, Server Password, Max Players (1-10),
  Region (`in:,SEA,EU` с 10-Nov 15:53), Beta Branch ID/Password, Auto Update. Скрыты AppID и WINDOWS_INSTALL.
- **Invite Code** вынесен на Overview (поле + Save + копирование). При создании сервера генерируется случайный
  (8 символов), правило `alpha_num|min:6|max:32`. Уникальность обеспечивает игра (ответ разработки).
- Конфиг сервера игры - `R5/ServerDescription.json`: перед стартом в него пишутся значения переменных
  (InviteCode, ServerName, MaxPlayerCount, UserSelectedRegion, DirectConnectionServerPort = порт аллокации).
- Лог игры `R5/Saved/Logs/R5.log`, при каждом старте прошлый уходит в `R5-backup-<дата>.log`. Консоль панели показывает
  хвост этого лога; консольных команд у сервера Windrose нет.
- Регистрация: `AuthenticateDedicatedServer` → `OnServerRegistered ... Registered` (~15 с после старта). При пустом Region
  игра пингует шлюзы eu/kr/ru и берёт лучший; шлюз `r5coopapigateway-ru-release` с ноды 412 недоступен.

## Итог QA
- 10-Nov (prod, 494912): AC 1-14 PASS. Покупка Deckhand → install ~1 мин, автостарт, регистрация; валидация переменных (422);
  применение после рестарта; экранирование `"` и `\` в имени; Start/Stop/Restart/Kill; File Manager (edit, upload, download,
  delete, zip, unzip); Reinstall без удаления файлов сохраняет мир, инвайт и настройки. **F1** - FAIL.
- 12-Nov ретест (встроенный браузер): F1, OBS-3, OBS-4 исправлены; OBS-1, OBS-2 закрыты ответом разработки.

## Находки
- **DEV-630/F1** (Medium, исправлен) Region = CIS → авторизация у шлюза ru-release падает по таймауту (408), сервер не
  регистрируется, панель показывает Running. Фикс: CIS убран из правила. **Остаток (Low, исправлен 12-Nov 11:11 UTC):** описание переменной было
  «Allowed: SEA, CIS, EU», теперь «Allowed: SEA, EU» (проверено в БД и на Config).
- **DEV-630/F2** (Low, открыт) После правки OBS-3 в шапке под тарифом «30 Slots | 8 Ram | 30 Days» у Deckhand (4 слота, 8 GB).
  На Minecraft-сервере блока нет. Поправят контентом.
- **DEV-630/OBS-1** Уникальность инвайт-кода в панели не проверяется - проверяет игра. Закрыто.
- **DEV-630/OBS-2** Битый `ServerDescription.json` → падение, автоперезапуск, игра создаёт новый мир (старый остаётся на диске).
  Решено ограничиться предупреждением.
- **DEV-630/OBS-3** «0/0 players online» в шапке. Исправлено (счётчик убран).
- **DEV-630/OBS-4** Пустой блок Server Properties на Config. Исправлено (блок убран).

## Гочи для следующего раза
- Полный лог читать через `GET panel.godlike.host/api/v2/servers/<uuid>/files/contents?path=/R5/Saved/Logs/R5.log`
  (тот же запрос делает File Manager); редактор CodeMirror виртуализирует длинный файл.
- Регистрацию у игры проверять по строке `OnServerRegistered`, статус Running в панели её не гарантирует.
- Ссылка `cart.php?a=add&pid=` на витрине редиректит на главную - заказ только через страницу игры.
