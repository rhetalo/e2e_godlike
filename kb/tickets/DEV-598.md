# DEV-598 - блок «Popular settings» на вкладке Settings Palworld

> **В двух словах.** На вкладке Settings Palworld-сервера сверху появился блок «Popular settings» с 12 самыми нужными
> настройками (имя, пароль, лимит игроков, рейты, смерть, PvP и т.д.). Настройки перенесены из своих категорий, а не
> продублированы. Сохранение пишет в те же ключи `PalWorldSettings.ini`. QA на проде 04-Nov: PASS 22/22.

## Что изменилось
- [new-panel!595](https://git.godlike.ovh/panel/godlike-new-panel/-/merge_requests/595), только фронт: массив
  `PALWORLD_POPULAR_SETTING_KEYS` в `helpers/palworld/popularSettings.ts` (состав и порядок блока) и функция
  `buildPalworldDisplayGroups`: блок первым, ключи вырезаются из категорий, опустевшая категория скрывается.
- Схема настроек и логика Save не менялись. Новый ключ перевода `Palworld_Settings.Groups.popular` только в `en.json`.

Порядок блока: `ServerName`, `ServerPassword`, `ServerPlayerMaxNum`, `ExpRate`, `PalCaptureRate`,
`PalEggDefaultHatchingTime`, `DeathPenalty`, `WorkSpeedRate`, `ItemWeightRate`, `BaseCampWorkerMaxNum`,
`CollectionDropRate`, `bIsPvP`. После переноса: Popular 12, Server 8, Time 3, Progress 4, Player 6, Pals 6, Base 6,
Gameplay 8, Cleanup 4 = 57 полей.

## Как это работает
Поведение вкладки - [UP/game-settings](../products/up/game-settings.md). Чтение и запись `.ini` через файловый API -
[API - files](../products/up/api/files.md#palworldsettingsini-чтение-и-запись).
