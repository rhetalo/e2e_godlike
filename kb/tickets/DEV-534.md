# DEV-534 - Фильтры «All» и «All versions» не расширяют список

> **В двух словах.** После правки [DEV-405](DEV-405.md) каталог модов по умолчанию показывает только то,
> что подходит серверу. Но выбор «All» в фильтрах ничего не менял: бэкенд снова подставлял ядро и версию
> сервера. Теперь «All» шлёт `any` и список действительно расширяется. QA 09-Oct-2026: PASS с двумя мелкими замечаниями.

## Что изменилось
- Раньше: пустой loader / mc_version бэкенд подменял значениями сервера, поэтому «All» = «как у сервера»;
  `loader=all` давал 0 результатов. Это бывшая находка DEV-405/B6.
- Теперь: «All» / «All versions» шлют `loader=any` / `mc_version=any`, значение видно в URL и держится после reload.
- Дефолт (пусто = под сервер) не тронут: на Forge 1.20.1 по умолчанию forge/1.20.1.
- Несовместимые моды в расширенном списке помечены Incompatible (Fabric API на Forge).

## Как это работает
- Каталог: `GET /api/v2/servers/{uuid}/minecraft/{mods|plugins}?loader=&mc_version=` (см. [DEV-405](DEV-405.md)).
- Префилл полей фильтра и заглушки зависят от [flag:extension-compatibility](../registry/flags.md#extension-compatibility):
  флаг Pennant считается по **владельцу сервера**. Под флагом `/minecraft/version` отдаёт `extension_capabilities`
  (заглушка Paper + префилл фильтров); без флага `null` - заглушки нет, поля пустые, но бэкенд всё равно сужает под сервер.
- На 09-Oct флаг `true` только у 3 пользователей (в т.ч. [acc:admin](../registry/test-accounts.md#admin)), глобально false.
