# DEV-515 - Loader gating: автофильтр модов и заглушки по ядру

> **В двух словах.** Панель теперь знает, какое ядро стоит на сервере, и сама подстраивает каталог: на Forge
> показывает Forge-моды под нужную версию, на Paper вместо модов показывает заглушку «только плагины», на Vanilla
> закрывает всё. Поставить несовместимое не даёт и бэкенд. QA 07-Oct-2026: PASS. Фича пока под флагом, флаг надо снять.

## Что изменилось
- Фильтры Loader + MC version в каталоге выставляются по ядру сервера (Forge, NeoForge, Fabric, Quilt, Arclight, Mohist, Paper-подобные).
- Попап версий мода показывает только совместимые, даже если пользователь сменил фильтр вручную
  («No compatible versions were found for your server.», Install disabled).
- Заглушки: Vanilla - Mods/Modpacks/Plugins; Paper-подобные и proxy - Mods/Modpacks; Forge/NeoForge/Fabric/Quilt - Plugins («mods only»). Тексты EN/UA/RU по ТЗ.
- Бэкенд режет установку: 409 `mods_not_supported`, `plugins_not_supported`, `modpacks_not_supported`,
  `incompatible_mod_loader`, `incompatible_game_version`, `incompatible_plugin_loader`.
- Версии плагинов фильтруются по версии MC (Paper 26.2 WorldEdit 50 -> 5 версий).
- Arclight определяется по flavor (`-forge` / `-neoforge` / `-fabric`), см. [DEV-529](DEV-529.md).

## Как это работает
- Источник правды: `GET /api/v2/servers/{uuid}/minecraft/version` -> `extension_capabilities`
  `{supports_mods, supports_plugins, supports_modpacks, mod_loader, game_version, enforced, plugin_loader}`.
- Под [flag:extension-compatibility](../registry/flags.md#extension-compatibility), Pennant, считается по **владельцу сервера**.
  Без флага `extension_capabilities = null`: заглушек нет, фильтры пустые (проверено на 0cf8346f).
- `/mods|plugins/{provider}-{id}/versions` игнорирует подменённые клиентом `loader` / `mc_version`.
- `POST /minecraft/modpacks` требует `install_mode` (валидно `overwrite`) + `world_folder`.
- `plugin_loader=spigot` остаётся при `supports_plugins=false` (наблюдение).
