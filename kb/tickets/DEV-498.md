# DEV-498 - Фильтр модов по загрузчику

> **В двух словах.** Во вкладке модов можно выбрать загрузчик (Forge, Fabric и т.д.). На CurseForge фильтр
> работал только вместе с выбранной версией Minecraft, а без неё показывал моды чужих загрузчиков. После фикса
> выдача чистая. QA 25-Sep-2026: PASS, остался мелкий хвост на NeoForge.

## Что изменилось
- До (24-Sep): CF + Fabric без версии MC - 10 из 45 модов первых страниц чисто Forge/NeoForge (Placebo, Curios API,
  Quark…); первая страница All / Forge / Fabric одинаковая, менялся только total.
- После (25-Sep): CF Fabric 0/152 нарушений (до стр. 277), поиск «quark» с Fabric -> 0 результатов, Quilt строго Quilt.
- Счётчики CF после фикса: All 10003, Forge 8518, NeoForge 5509, Fabric 4142 (было 6161), Quilt 1341.
- Modrinth был корректен и до фикса.

## Как это работает
- API: `GET /servers/{uuid}/minecraft/mods?provider=&search=&loader=&mc_version=&page=&per_page=15&sort_by=downloads`.
  В ответе нет списка загрузчиков мода - сверка шла с первоисточниками.
- Гоча CurseForge: фильтр загрузчика применяется только в паре с версией игры; панель передавала loader как есть.
- Эталон для проверок: CF `curseforge.com/api/v1/mods/{id}/files?pageSize=50&pageIndex=N` (`gameVersions`),
  Modrinth `api.modrinth.com/v2/projects?ids=[..]` (`loaders`).
- UI принимает фильтры из URL: `?provider=&loader=&page=&mc_version=&search=`.
- На 24-Sep каталог шёл из БД (count 10003); переключение на live API - позже, в [DEV-405](DEV-405.md).
