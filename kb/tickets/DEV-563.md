# DEV-563 - Free-серверам запрещена смена типа сервера

> **В двух словах.** У бесплатного сервера нельзя поменять игру или тип сервера: это доступно только на платных
> тарифах. В новой панели поля смены просто убраны, а бэкенд отклоняет попытку в обход интерфейса. QA 15-Oct-2026:
> защита работает везде, но на PlayFreeHost ещё стоит старый фронт, где поля видны (сохранить всё равно не даёт).

## Что изменилось
- ultra.panel, Edit Server у free-сервера: только имя, полей Game/Platform и Server Type нет; переустановка не предлагается.
- Бэкенд: смена nest/egg у free-сервера -> 403 «Changing the server type is only available on paid plans.»
  Отказ атомарный: имя из того же запроса тоже не сохраняется. Текст ошибки виден пользователю.
- Подделать признак `free` / `free_timer` в PUT нельзя (mass assignment игнорируется; `free:false` + чужой egg -> 403, проверка по БД).
- Платные серверы: поля на месте, смена типа и переустановка работают как раньше.

## Как это работает
- Бэкенд общий для ultra.panel и панели PlayFreeHost (`playfreehost.com/panel` - дубль ultra для фришников, аккаунты синхронны),
  поэтому защита действует в обеих.
- Признак free в panel DB - только `servers.free`, связи с продуктом WHMCS нет. Free-продукты WHMCS 282 и 1127 (US / не-US),
  группа Free Tariffs (Hidden); суффикс имени `_NNNNNN` = ID услуги WHMCS.
- Free бывают и не-MC (напр. «Terraria (USA) Free server»).
- `activity_logs` смену egg не пишет.
- Суть тикета (решение владельца 15-Oct) - запрет смены **игры**; смена версии/платформы MC на Versions, модпаки,
  Import/Reinstall, удержание - вне сути (N/A).
